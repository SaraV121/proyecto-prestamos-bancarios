# Sistema de Préstamos Bancarios

## Tecnologías

- React
- NestJS
- PostgreSQL
- JWT
- reCAPTCHA
- Chart.js
- jsPDF

## Funcionalidades

- Registro de usuarios
- Inicio de sesión
- Roles (Administrador y Empleado)
- Gestión de clientes
- Gestión de préstamos
- Reportes PDF
- Estadísticas
- Logs de acceso
- Versión móvil responsive

## Instalación

### Backend

```bash
npm install
npm run start:dev
```

### Frontend

```bash
npm install
npm run dev
```

PostgreSQL
